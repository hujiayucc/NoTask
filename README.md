# NoTask

NoTask 是一个基于 Modern Xposed API 101/102 的最近任务管理模块，可按应用控制任务卡片从系统最近任务列表隐藏的时机。模块只调整任务卡片的可见性，不结束应用进程，也不阻断应用原有的返回逻辑。

## 功能

- **返回键隐藏**：仅在任务根 Activity 按下返回键时隐藏任务卡片，应用内页面返回保持原有行为。
- **后台自动隐藏**：应用的全部 Activity 进入后台后自动隐藏，应用内页面切换不会误触发；再次进入前台时恢复可见。
- **按应用独立配置**：每个已启用应用可以分别选择隐藏方式，未配置时默认使用返回键隐藏。
- **动态作用域管理**：在模块主页直接添加或移除应用作用域，无需手动维护静态作用域列表。
- **配置实时生效**：通过 Remote Preferences 同步设置，目标进程载入模块后可实时响应模式变化。
- **模块状态与应用管理**：显示框架连接和模块激活状态，支持搜索应用及查看已启用数量。
- **界面适配**：支持深色模式、沉浸式状态栏和透明导航栏。

## 使用方法

1. 安装 NoTask，并在支持 Modern Xposed API 的框架中启用模块。
2. 打开 NoTask，确认主页显示“模块已激活”。
3. 为目标应用打开作用域开关，并在框架弹窗中批准请求。
4. 选择“返回键”或“进入后台”隐藏方式。
5. 首次加入作用域后重新启动目标应用；后续模式修改可实时生效。

## 兼容性

- Android 8.0（API 26）及以上。
- Modern Xposed API：最低 101，目标 102。
